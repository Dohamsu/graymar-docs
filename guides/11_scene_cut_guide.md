# 장면 컷 제작·투입 가이드 (arch/96)

> 대상: 팩 소유자. 상황 이미지를 미리 생성·태그화해 넣으면 서술과 태그 매칭으로
> 스토리 로그에 인라인 삽입되는 시스템의 **제작 규약 + 생성 프롬프트 템플릿**.
> 시스템 설계·게이트 상세는 [[../architecture/96_inline_image_insertion|arch/96]].

## 1. 삽입 소스 3종 — 무엇이 언제 뜨나

| 종류 | 소스 | 삽입 조건 | 소유자가 할 일 |
|------|------|----------|---------------|
| **장면 컷** (주력) | `content/<pack>/assets/scenes/` | 서술이 태그와 겹치고 nano가 "장면의 핵심 상황과 일치" 판정 | **이 가이드로 제작·투입** |
| 인물 컷 | 초상화 풀 (기존 portraits/ 또는 정적 맵) | 서술에 등장한 **소개 완료** NPC가 장면의 중심일 때 (소개 카드 턴 제외) | 초상화만 있으면 자동 — 추가 작업 없음 |
| 장소 컷 | `assets/locations/` (arch/80 팩만) | **현재 장소**의 묘사가 서술에 두드러질 때 (진입 턴 제외 — 진입 컷은 별도 기구현) | 장소 이미지만 있으면 자동 |

공통 빈도 제어: **쿨다운 3턴 (종류 무관 단일) + 런 내 같은 이미지 1회**.
graymar_v1처럼 장소 이미지가 클라 정적 경로인 팩은 장소 분위기 컷을 **scenes/로** 넣는다.

## 2. 장면 컷 파일명 = 태그 규약

```
content/<pack>/assets/scenes/시장_난투_군중_웅성_night.webp
                              └─┬─┘└─┬─┘└──── 태그 (2~4개 권장)
                                │    └ 행위·분위기
                                └ 장소·소재
```

- 토큰 구분: `_` 또는 `-`. **토큰이 곧 매칭 태그** — 서술 본문에 이 낱말이 실제
  등장해야 후보가 된다 (렉시컬 프리스크린). LLM 서술이 실제로 쓰는 어휘로 태그를 정할 것.
- `day` / `night` (낮/밤) 토큰은 시간대 제한으로 분리 — 해당 시간대에만 후보.
  무표기 = 전 시간대.
- 숫자·1글자 토큰은 무시 (일련번호용).
- 투입 후: `python3 scripts/sync_pack_assets.py <packId>` → **서버 재시작** → client push.
  파일명은 ASCII 슬러그(scene_NN.webp)로 정규화되고 태그는 매니페스트에 보존된다.

### 태그 선정 원칙 (매칭 품질의 전부)

1. **서술 어휘로 태그를 짓는다** — "brawl"이 아니라 "난투·주먹·몸싸움". LLM이 한국어로
   서술하므로 태그도 한국어 일반 명사가 잘 걸린다.
2. **동의어는 태그를 나눠 붙인다** — 난투 컷이면 `난투_주먹다짐_몸싸움` 처럼 같은
   상황의 표현 변형을 2~3개 병기 (프리스크린은 하나만 겹쳐도 통과, 최종 판정은 nano).
3. **과잉 일반어 금지** — "사람", "거리", "밤" 단독은 아무 서술에나 걸려 nano 부하만
   늘린다. 장소·행위와 결합해 구체화할 것.
4. **한 컷 = 한 상황** — 여러 상황을 겨냥한 만능 컷은 confidence가 낮게 나와 안 뜬다.

## 3. 우선 제작 목록 — 고빈도 장면 유형

실측(장소 세션 서술 분포) 기준, 트리거 이벤트 없이 대화·행동만 이어지는 구간에서
자주 나오는 상황부터 만들면 노출 효율이 높다. 팩당 12~20장 권장 (과다 투입해도
쿨다운 때문에 노출은 제한 — 다양성이 올라갈 뿐).

| 유형 | 태그 예 | 비고 |
|------|--------|------|
| 술집·식사 자리 | `선술집_술잔_왁자지껄`, `식사_스튜_김` | 대화 최다 무대 |
| 뒷골목 밀담 | `골목_밀담_속삭임_night`, `그림자_미행` | 음모물 단골 |
| 난투·소동 | `난투_주먹다짐_몸싸움`, `소란_군중_웅성` | 전투 전후 |
| 조사·수색 | `장부_서류_촛불`, `수색_흔적_바닥` | INVESTIGATE 턴 |
| 거래·뇌물 | `거래_금화_손`, `뇌물_주머니` | 경제 루프 |
| 경비·검문 | `경비_창_갑옷`, `검문_횃불_night` | 경비대 지구 |
| 날씨·정경 | `비_젖은돌바닥_night`, `새벽_안개_항만` | 전환·휴지 턴 |
| 부상·치료 | `붕대_상처_치료`, `약초_연고` | 회복 장면 |

## 4. 생성 프롬프트 템플릿

공통 스타일 프리픽스 (guides/09 카른홀트와 동일 계열 — 팩 톤에 맞게 조정):

```
Dark fantasy medieval illustration, painterly style, muted earthy palette,
dramatic chiaroscuro lighting, gritty realism, no text, no watermark,
cinematic wide composition, 16:9
```

유형별 본문 예:

```
[뒷골목 밀담] two hooded figures whispering in a narrow rain-slick alley at
night, single lantern glow, long shadows, tension
→ 파일명: 골목_밀담_속삭임_night.webp

[선술집] crowded medieval tavern interior, wooden tables with ale mugs,
warm hearth light, lively patrons mid-conversation
→ 파일명: 선술집_술잔_왁자지껄.webp

[조사] close-up of weathered ledger pages and ink pot on a desk lit by a
single candle, magnifying scrutiny mood
→ 파일명: 장부_서류_촛불.webp
```

제작 시 주의:
- **특정 인물 얼굴을 넣지 않는다** — 인물은 초상화 풀 소관. 장면 컷에 얼굴이 크게
  나오면 "누구지?" 오귀속 위화감이 생긴다. 뒷모습·실루엣·군중은 무방.
- 가로형(16:9 내외) 권장 — 클라 렌더가 카드 폭 기준 220~320px 높이 크롭.
- webp 변환 후 투입 (png/jpg도 허용되나 용량 큼).

## 5. 운영·튜닝

- 킬스위치: `INLINE_IMAGE_MATCH_DISABLED=1` (서버 env)
- 채택 임계: `SCENE_CUT_MIN_CONFIDENCE` (기본 0.65 — 오매칭 보이면 0.75로)
- 발화 로그: 서버 로그 `[SceneCut] turn=N 삽입 SCN_xx (kind=…, conf=…)` — 삽입
  빈도·매칭 품질 점검용. 무삽입은 정상 동작 (풀이 빈약하면 조용히 안 뜬다).
- 컷 교체: 파일 삭제/추가 후 sync 재실행이면 끝. id(SCN_NN)는 정렬 순서라 **파일을
  중간 삭제하면 뒤 번호가 밀린다** — 진행 중 런의 usedIds와 어긋날 수 있으니 대량
  교체는 한 번에 (새 런부터 정합).
