## 1. 처방 4건

### ① 대화 잠금 턴 장면 리셋 금지 (D-개시 0%의 직접 처방)

대화 잠금(RENEW/HOLD) 턴은 [첫 문장 지시]로 "장면을 처음부터 다시 묘사하지 말고
{상대}의 반응(대사·표정·동작)으로 바로 시작"을 주입. 서버가 이미 아는 상태
(`ctx.conversationLock`)라 오탐 없음. P1-B(장면 연속성)와 정합.

### ② 개시 유형 결정론 로테이션

`llm/prompts/opener-directive.core.ts` — 유한 4유형 {ACTION_RESULT, NPC_MOTION,
SENSE, ENVIRONMENT} 링 워크. `fnv1a(nodeInstanceId)` 로 방문마다 시작점·보폭이
다르고, **연속 턴은 항상 다른 유형** (스펙 보증). 저장 없는 순수 함수 — RNG cursor
(불변식 4) 비소모. 게이트:

- 잠금 턴 → ① 우선 (로테이션 미적용)
- 진입 턴(MOVE_LOCATION)·HUB → 지시 없음 (환경 개시가 자연스러움)
- 그 외 LOCATION 턴 → 로테이션 유형 1줄
- 직전 턴 "당신" 개시 감지 시 방어 라인 병기 (구 [첫 문장 지시] 동작 계승 — 구
  블록은 이 경우에만 발화하던 좁은 장치였고 본 확장이 대체)

P0-E는 "[첫 문장 지시] 블록이 있으면 그 개시 유형을 따를 것"으로 개정. 유형
지시문은 구성 요소만 — 구체 예문 금지 (불변식 50, 구 블록의 "골목 어딘가에서
쇳소리가 울린다" 예문 제거).

### ③ 팔레트 샘플링 + 시간대 힌트 축약 (anchor 해체)

- [세계 감각 팔레트] 시스템 프롬프트 블록 **삭제** — 시스템 프롬프트는 런 전체
  고정(prefix 캐싱 대상)이라 턴별 변주 불가. 대신 user 프롬프트 [세계 감각 힌트]에
  턴마다 **서로 다른 카테고리 2개에서 1개씩 샘플** 주입 ("0~1개만, 쓰지 않아도
  됩니다"). 잠금 턴은 미주입 (사건·대화 중심).
- [현재 시간대] 상세 광원 힌트(팩 phaseHints 산문 포함)는 **전환·진입 턴에만**.
  체류 중 비전환 턴은 "직전 턴과 동일" 한 줄 + 모순 금지만. 대화 중 시간이 흐르지
  않으므로(불변식 49) 같은 힌트 반복 주입은 순수 anchor 공급이었다.

### ④ 사교 발화 분량 변주

`dialogueAct ∈ {GREETING, WELLBEING, THANKS, FAREWELL}` 턴에 [분량 지시]
"1~2문단(총 3~5문장)" 주입. 매 턴 비슷한 길이(4문단+ 72%)도 정형감의 일부 — 잡담
턴에 리듬 완급. **워커 ShortResponse 재시도는 이 턴을 스킵** — 짧게 쓰라고 지시한
턴의 짧은 응답(<150tok)을 교차 모델 실패로 오판해 재시도(이중 과금)하는 함정 차단.
