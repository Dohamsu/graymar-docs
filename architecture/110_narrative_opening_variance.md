# 110. 서술 개시 다양화 — 정형 구조 해체 (2026-08-27)

## 0. 출발점

소유자 관찰: "턴 진행이 정형적 — 처음 3줄 주변 묘사, 이후 내레이션, 이런 프롬프트가
정해져 있나?" → 실측으로 검증하니 감각이 아니라 수치였다.

### 실측 (최근 45일 LOCATION 800턴, `scripts/analyze_narrative_structure.py`)

| 지표 | 값 | 해석 |
|------|-----|------|
| 첫 문장 유형 | 환경·감각 48.6% + 시간대 11.4% = **60%** | P0-E("환경으로 열 것") 고정 규칙의 산물 |
| 대사(D) 개시 | **0%** | 대화가 이어지는 중에도 매 턴 장면 리셋 |
| 첫 대사 위치 | 2~3문단 64% | "묘사 2~3문단 → 대사" 템플릿 고착 |
| 첫 두 단어 최빈 | **"푸르스름한 여명이" 6.2%** (50/800) | 주입 데이터 합성 anchor (아래) |
| 첫 단어 상위 | 푸르스름한 7.0% / 차가운 5.8% / 이른 5.1% | 시간대·냉기 어휘 편중 |
| 문단 수 | 4문단 이상 72% | P2-B "3문단 이하"는 이미 사문 — 분량은 모델 관성이 결정 |
| 종결 | 대사 31% + 소리 18% + 시선 11% | P1-E 종결 규칙 수렴 |

표본 유의: 최근 관계 엔진 검증 런(star_sand)이 다수 포함되어 오프닝 **어휘** 편중은
다소 과장 가능. 구조 지표(D-개시 0%·대사 위치·문단 시퀀스)는 팩 무관.

### 원인 — 규칙과 데이터가 모두 "매 턴 동일"

1. **P0-E 고정 규칙**: "첫 문장은 환경(바람/소리/빛)·NPC·사물로 열 것" — "당신은" 개시
   편중(15.3%)의 처방이었으나, 매 턴 같은 지시라 환경 개시로 재수렴.
2. **매 턴 동일 데이터 주입**:
   - 시스템 프롬프트 [세계 감각 팔레트] — 전체 풀 상시 노출 (arch/73 A4)
   - [현재 시간대] 팩 phaseHints — **산문 그대로** 매 턴 주입. 불변식 50 처방(전보체
     전환, 2026-07-27)이 기본 힌트에만 적용되고 팩 오버라이드는 누락된 사각지대.
     star_sand DAWN "수평선이 옅게 물들 뿐… 오로라가 흐릿해진다" + 팔레트 "푸른
     인광" → LLM이 합성한 것이 "푸르스름한 여명이" 6.2%.
3. 저모델 수렴: 비슷한 context → 비슷한 출력 (LLM 설계 원칙 3). 개별 규칙은 전부
   실측 결함의 처방이었는데, 합쳐지니 템플릿이 됐다.

soft 지시로 풀 수 없다는 것도 기실측 — arch/78 개시어 억제가 soft 라인으로 상대
-20%에 그침(천장). 처방은 **규칙 고정 → 데이터 변주** 전환.

## 1. 처방 4건

### ① 대화 잠금 턴 장면 리셋 금지 (D-개시 0%의 직접 처방)

대화 잠금(RENEW/HOLD) 턴은 [첫 문장 지시]로 "장면을 처음부터 다시 묘사하지 말고
{상대}의 반응(대사·표정·동작)으로 바로 시작"을 주입. 서버가 이미 아는 상태
(`ctx.conversationLock`)라 오탐 없음. P1-B(장면 연속성)와 정합.

### ② 개시 유형 결정론 로테이션

`llm/prompts/opener-directive.core.ts` — 유한 4유형 {ACTION_RESULT, NPC_MOTION,
SENSE, ENVIRONMENT} 링 워크. `fnv1a(nodeInstanceId)` 로 방문마다 시작점·보폭이
다르고, **연속 턴은 항상 다른 유형** (스펙 보증). 저장 없는 순수 함수 — RNG cursor
(불변식 4) 비소모. 게이트:

- 잠금 턴 → ① 우선 (로테이션 미적용)
- 진입 턴(MOVE_LOCATION)·HUB → 지시 없음 (환경 개시가 자연스러움)
- 그 외 LOCATION 턴 → 로테이션 유형 1줄
- 직전 턴 "당신" 개시 감지 시 방어 라인 병기 (구 [첫 문장 지시] 동작 계승 — 구
  블록은 이 경우에만 발화하던 좁은 장치였고 본 확장이 대체)

P0-E는 "[첫 문장 지시] 블록이 있으면 그 개시 유형을 따를 것"으로 개정. 유형
지시문은 구성 요소만 — 구체 예문 금지 (불변식 50, 구 블록의 "골목 어딘가에서
쇳소리가 울린다" 예문 제거).

### ③ 팔레트 샘플링 + 시간대 힌트 축약 (anchor 해체)

- [세계 감각 팔레트] 시스템 프롬프트 블록 **삭제** — 시스템 프롬프트는 런 전체
  고정(prefix 캐싱 대상)이라 턴별 변주 불가. 대신 user 프롬프트 [세계 감각 힌트]에
  턴마다 **서로 다른 카테고리 2개에서 1개씩 샘플** 주입 ("0~1개만, 쓰지 않아도
  됩니다"). 잠금 턴은 미주입 (사건·대화 중심).
- [현재 시간대] 상세 광원 힌트(팩 phaseHints 산문 포함)는 **전환·진입 턴에만**.
  체류 중 비전환 턴은 "직전 턴과 동일" 한 줄 + 모순 금지만. 대화 중 시간이 흐르지
  않으므로(불변식 49) 같은 힌트 반복 주입은 순수 anchor 공급이었다.

### ④ 사교 발화 분량 변주

`dialogueAct ∈ {GREETING, WELLBEING, THANKS, FAREWELL}` 턴에 [분량 지시]
"1~2문단(총 3~5문장)" 주입. 매 턴 비슷한 길이(4문단+ 72%)도 정형감의 일부 — 잡담
턴에 리듬 완급. **워커 ShortResponse 재시도는 이 턴을 스킵** — 짧게 쓰라고 지시한
턴의 짧은 응답(<150tok)을 교차 모델 실패로 오판해 재시도(이중 과금)하는 함정 차단.
