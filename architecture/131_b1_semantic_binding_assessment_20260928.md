# 131. B1 라벨↔대상 독립 의미 검사 — 격리 실측 (2026-09-28)

## 범위와 계약

- 서버 시작점 `ad8b53e`에서 `CHOICE_GROUNDING_PROPOSAL_EXPERIMENT=true`와 별도 `CHOICE_GROUNDING_SEMANTIC_SHADOW=true`를 **함께** 켠 격리 평가다. 기본값은 둘 다 꺼져 있다. 포트 3015·격리 DB `graymar_p3_e2e_20260927`만 사용했고 운영 서버·DB는 변경하지 않았다.
- 최종 Nano 선택지 라벨과 공개 정본 참조의 대상 설명을 JEV가 독립적으로 비교한다. Nano가 제안한 ID가 유효하다는 이유로 의미 일치를 승인하지 않는다. 대상 동일성(`SAME/DIFFERENT/UNCLEAR`)과 존재 질문/물리적 행동(`ASK_EXISTENCE/ACT_ON_OBJECT/OTHER`)을 한 배치에서 질문한다. 확신도 0.8 미만·미응답·모델 오류는 `UNVERIFIED/ERROR`로 보수적으로 남긴다.
- 이 결과는 기존 구조 shadow 로그에 덧붙이는 **후보 신호**다. 최종 선택지, 저장 payload, 클릭, 하드 상태, 차단 여부는 바꾸지 않는다. 비공개 fact와 내부 NPC ID는 JEV 입력 대상 설명으로 보내지 않는다.

두 실런을 합치면 구조 `CONTRADICTED 26 / STRUCTURE_MATCH 9`이고, 별도 의미 검사의 35개 신호는 `TARGET_MISMATCH 1 / UNVERIFIED 34`다. 유효한 **공개 targetRef**가 있는 선택지는 4개뿐이었다. 나머지는 상당수가 Nano의 내부 NPC ID/없는 ID/빈 대상 제안이라 대상 동일성 질문 자체를 하지 않았다. 따라서 `1/35`를 의미 검사의 민감도나 문제 선택지 발생률로 읽으면 안 된다. 열린 존재 질문 신호는 실런에서 0건이었고, 표적 탐침에서만 확인했다.

구체적으로 극야해안 T12 `nano_12_0`의 최종 라벨은 “부적을 더 가까이 살펴본다”였는데 targetRef는 플레이어의 별자리 도표 `ITEM:ITEM_SS_STAR_CHART`였다. 구조 검사는 `STRUCTURE_MATCH`, JEV는 별개 대상으로 `DIFFERENT`(0.83)·`ACT_ON_OBJECT`(0.98)를 반환했다. 기존 검사가 놓친 **유효하지만 다른 대상** 사례를 한 건 포착한 것이다. 다만 T13의 다른 부적→도표 연결은 동일성 확신도 0.79로 보류됐다. 같은 계열을 안정적으로 포착했다고 말할 수 없다.

JEV 배치 12회는 모두 `EVALUATED`, 호출 지연은 213–863ms(중앙값 240.5ms, 관측 p95 863ms), 합계 비용은 약 $0.00069였다. 호출은 최종 선택지 저장 전에 동기적으로 기다리므로 플래그를 켜면 그만큼 턴 완료를 늦출 수 있다. **플래그 OFF 동일 자극 대조가 없어 전체 턴 p50/p95 지연 차이는 미측정**이다. 의미 원자료는 [[architecture/130_b1_semantic_shadow_20260928.json|§130]], 같은 최종 표면의 35개 라벨·전체 payload·바로 다음 테스트 입력/클릭 8건은 [[architecture/132_b1_semantic_surface_20260928.json|§132]]에 보관했다. 원본 플레이테스트 JSON 경로는 §130에 있다. §132의 클릭은 에이전트 런에서 다음 입력으로 선택한 증거이며 사람의 `REJECT/ALLOW` 판정이 아니다.

## 판단과 다음 관문

이번 블록은 B1의 라벨↔대상 검증 계약 중 **동일 대상·존재 질문/행동 전제 첫 슬라이스**와 격리 계측을 구현·작동 확인했다. 공개 소유자·사실 전달 매체·시점의 일치, 비공개 사실의 질문/단정 구분은 아직 계약에 넣지 않았다. JEV 단독으로 B2를 승인하지 않는다. 다음은 (1) 공개 참조 형식 미준수 때문에 의미 검증 대상에서 빠진 Nano 제안 원인을 분석하고, (2) 동일 최종 표면의 정상/문제 사람 판정을 붙여 후보 신호의 오경보·미검출을 산출하며, (3) OFF 대조로 전체 지연을 측정하는 순서다. 정상 질문을 부재로 간주하거나 문구별 명사 규칙을 늘리지 않는다. B2 활성화, P3-2/P2-E 완료, 출시 판단은 계속 보류한다.

추가 한계: JEV에는 현재 본문 앞 650자만 전달한다. 긴 장면의 대상 언급이 뒷부분에만 있다면 이 첫 슬라이스는 이를 보지 못한다. 분모가 갖춰질 때 본문 맥락 길이도 정확도·지연 변수로 비교해야 한다.
